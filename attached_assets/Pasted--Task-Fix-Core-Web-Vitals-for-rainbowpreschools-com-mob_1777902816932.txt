## Fix priority order (highest impact first)

### Priority 1: Fix CLS = 0.46 (URGENT)
CLS this high means above-the-fold content is jumping around as the page loads. Almost always caused by:
- **Images without explicit `width` and `height` attributes** → browser reserves 0px, then jumps when image loads
- **Web fonts swapping** without size-adjust → text reflows when custom font loads
- **Banners/popups/cookie notices/sticky headers** that inject after first paint
- **Lazy-loaded sections** without reserved minHeight placeholders
- **CSS animations with `transform` that move layout-affecting elements**

Actions:
1. Audit every `<img>` and `<picture>` on the home page and all above-fold sections. Add explicit `width={N}` and `height={N}` matching the image's intrinsic aspect ratio.
2. For background images that are LCP candidates, set `aspect-ratio` or fixed `min-height` on the container.
3. If using Google Fonts, add `font-display: swap` AND set `size-adjust`, `ascent-override`, `descent-override` in the @font-face fallback declaration to prevent text reflow on font swap.
4. Any popup/banner/cookie notice/announcement bar that appears after page load → reserve its space with a placeholder div, OR mount it inside a `position: fixed` overlay (overlays don't cause layout shift).
5. If hero has a slider/carousel, ensure the container has fixed height before slides mount.

### Priority 2: Fix LCP = 3.6s
Likely causes (check in this order):
1. **Hero image too large** — convert to WebP, create a separate mobile-sized variant (~800px wide), use `<picture>` with `<source media="(max-width: 768px)" srcSet="...mobile.webp">`. Add `fetchPriority="high"` and `loading="eager"` to the LCP image.
2. **Add `<link rel="preload" as="image">`** in the `<head>` for the hero image with `imagesrcset` and `imagesizes` attributes for responsive preload.
3. **TTFB is 1.5s** — check server response. If using WordPress/Hostinger, enable page caching (LiteSpeed Cache or W3 Total Cache). If using a server framework, ensure home page is either statically generated or aggressively cached at the CDN edge (Cloudflare).
4. **Render-blocking CSS** — inline critical above-fold CSS, defer the rest.
5. **Render-blocking fonts** — add `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>`. Self-host fonts if possible.

### Priority 3: Fix INP = 263ms and TBT
Long-running JavaScript on the main thread blocks user interaction.
1. **Defer all third-party scripts** (Google Tag Manager, GA4, Facebook Pixel, chat widgets, WhatsApp button scripts) to load AFTER `window.load + 2 seconds` using a small inline scheduler:
   ```js
   window.addEventListener('load', () => {
     setTimeout(() => {
       // inject GTM/GA4/FB Pixel/etc here
     }, 2000);
   });
   ```
2. **Code-split below-the-fold sections.** If using React, use `React.lazy()` + `<Suspense>` AND wrap each below-fold section in an IntersectionObserver-based `<LazyVisible>` component that only mounts the section when within 300px of viewport. (`React.lazy` alone does NOT defer rendering — you need IntersectionObserver to actually defer.)
3. Remove or replace expensive CSS animations (`animate-ping`, `animate-pulse` on multiple elements). Use static `box-shadow` instead.
4. Audit the main JS bundle. Remove unused dependencies. Check for accidentally-imported large data files (blog post arrays, etc.) on the home page.

### Priority 4: Image optimization (sitewide)
1. Convert all PNG/JPG images > 100KB to WebP using ffmpeg:
   ```
   ffmpeg -i input.jpg -c:v libwebp -quality 80 output.webp
   ```
2. For hero/above-fold images, also generate a mobile variant at 800px width.
3. Use `<picture>` with `<source type="image/webp">` and a JPG/PNG fallback `<img>` for browser compatibility.
4. Add `loading="lazy"` and `decoding="async"` to all below-fold images.
5. Add explicit `width` and `height` to every single image (also fixes CLS).

### Priority 5: Cache and delivery
1. Set `Cache-Control: public, max-age=31536000, immutable` on all hashed static assets (JS, CSS, images in `/assets/`).
2. Add `<link rel="preconnect">` for any third-party domains used above the fold (fonts, CDN, image host).
3. Enable Brotli/gzip compression on the server.
