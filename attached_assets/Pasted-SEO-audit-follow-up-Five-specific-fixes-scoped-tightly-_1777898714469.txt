FIX 5 — Verify the Replit subdomain is not indexable

Production has three domains visible: rainbow-preschool.replit.app, 
rainbowpreschools.com, www.rainbowpreschools.com. Only www.* should be 
indexable.

Curl https://rainbow-preschool.replit.app/robots.txt and check whether it 
disallows all crawlers. It should be:

  User-agent: *
  Disallow: /

If the Replit subdomain serves the same robots.txt as production (which 
allows crawlers), Google may be indexing it as a duplicate of the main 
site. Two ways to fix:

  Option A: serve a different robots.txt on the Replit subdomain only 
  (detect via Host header in Express, return Disallow: / when host matches 
  *.replit.app).

  Option B: add <meta name="robots" content="noindex"> to all responses 
  when Host header is *.replit.app.

Implement Option A — it's cleaner and prevents indexing at the crawl 
stage rather than the index stage. Report which Host headers you matched 
on and confirm www.rainbowpreschools.com still serves the normal 
robots.txt.
