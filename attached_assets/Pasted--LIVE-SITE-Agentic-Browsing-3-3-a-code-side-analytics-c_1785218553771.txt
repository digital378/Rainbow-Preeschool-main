## 2. Agent-Centric Accessibility — names, roles, tree integrity (also fixes Accessibility 89)
- Every interactive control needs an accessible NAME + correct ROLE, present in the a11y
  tree. Add aria-label to icon-only controls: dark-mode toggle, hamburger menu, chat
  bubble, WhatsApp/phone icon buttons, map pins, carousel arrows.
- Real semantic landmarks (<header><nav><main><footer>); real <button>/<a> (not divs with
  onClick); decorative icons/SVGs get aria-hidden="true".

## 3. Stability — CLS < 0.1
- Explicit width/height (or aspect-ratio) on EVERY <img>/media/canvas box; reserve
  min-height for the hero, the lazy 3D map box, and lazy/animated sections; font-display:
  swap + size-adjusted fallback + preload the hero heading font. No content injected above
  existing content without reserved space.
