# Rainbow Preschool — /dummy walkthrough kit: start here

This kit (three zip files) lets Replit build the 3D walkthrough on your `/dummy` page. It is a private test page: password-protected, never indexed by Google, and the live homepage stays untouched.

## What's inside

- **`client/public/walkthrough/`** — all the media Replit needs:
  - the walkthrough videos at full resolution (mobile + desktop), plus a lighter mobile version for slow connections
  - 16 scene stills
  - the 3D counsellor model
  - a list of every file (`manifest.json`)
- **`reference/walkthrough-prototype.html`** — the approved preview, for the Agent to copy the behaviour from.
- **`REPLIT_AGENT_PROMPT.md`** — the instructions you paste into Replit Agent.

## Step by step

1. **Download all three zips** from our chat: `rps-walkthrough-kit-part1.zip`, `part2` and `part3`. The kit was too big for one download. Part 2 is the mobile video and part 3 is the desktop video.
2. **Open your Rainbow Preschool project in Replit.**
3. **Set the password for /dummy** (do this before anything else):
   - Open the **Secrets** tool. It has a padlock icon; you can also find it through the search bar or the "All tools" list.
   - Click **New Secret**. Key: `DUMMY_PASSWORD`. Value: a password you choose. Save.
   - Click **New Secret** again. Key: `DUMMY_USER`. Value: `rainbow`, or any username you like. Save.
   - Without this password the page stays locked for everyone, including you. That's deliberate.
4. **Upload the zip:** in the **Files** panel on the left, drag **all three** zip files onto the top level of the file list. You can also use the three-dot menu (⋮) and choose **Upload file**. Together they're about 70 MB, so give it a few minutes.
5. **Open the Agent tab.** Open `REPLIT_AGENT_PROMPT.md` (from the chat or after unzipping), select all of it, copy it, paste it into Agent and send.
6. **Let the Agent work.** It will unzip the kit, lock /dummy first, then build the page on a separate branch called `dummy-walkthrough-v6`. If it asks you to approve a plan or a step, read it and approve. If it asks to change files outside /dummy, say no and send me the question.
7. **See the page:**
   - Open the preview (Webview) and click its **open in a new tab** icon. The password box doesn't show inside Replit's small preview window.
   - In the new tab, add `/dummy` to the end of the address.
   - Your browser will ask for the username and password from step 3.
8. **Testing the form:** a callback submitted on /dummy goes to the real admissions inbox, just like the homepage form. Type **TEST** as the parent name so the team knows to ignore it.
9. **Don't click Deploy/Publish yet.** Review it in the preview first. If you do deploy later, /dummy stays password-locked and hidden from Google.

## When the Agent finishes

Send me its report: the file list, curl results, screenshots and Lighthouse scores. I'll check it before we decide anything about the real homepage.

## Things you should know

- **The counsellor's arms don't move yet.** Higgsfield didn't deliver the rigging we paid for. She breathes, turns, hops, follows your mouse and reacts, but can't wave with her hand. If you get the rigged version later, just replace `counsellor.glb`; the page already knows to play wave/point/clap animations when they exist.
- **The Theatre shows placeholders** until you connect Instagram. The Agent is told to read reels from `/api/instagram/reels`, newest first, so that's the endpoint to build when you connect it.
- **The AI artwork has a few text mistakes**: the Kindergarten door sign in the corridor reads "Kindergerten", and the aerial scene has AI-drawn map labels (for example "Thane (HQ)"). These are fine for a test page but must be fixed before anything goes live.
