## Functional Requirements

### 1) Light & Dark Mode Support

* Section background, text, and logo treatment must adapt to **Light and Dark themes**.
* Use theme tokens / CSS variables already present (preferred), e.g.:

  * `--bg`, `--text`, `--muted`, `--card`, `--border`, etc.
* Title text should remain high contrast in both modes.
* Logos should look clean in both themes:

  * If logos are colored PNG/SVG, keep as-is.
  * If logos are single-color SVGs, allow tinting via CSS (optional).

### 2) Responsive Layout (Mobile → Desktop)

* **Mobile:** show the logos in a single row with **Right-to-Left continuous scrolling** (marquee-like).
* **Tablet / Laptop / Desktop:** no marquee. Show as a centered static row/grid with **hover zoom-in** and **soft shadows per logo card**.

Breakpoints (suggested, adjust to your design system):

* Mobile: `< 768px` → scrolling RTL
* Large screens: `>= 768px` → static layout + hover effects

### 3) Mobile Right-to-Left Scrolling Behavior

* Implement a smooth, continuous loop (no jump).
* Logos should scroll **from right to left**.
* Pause animation on touch/hover is optional but nice.
* Must respect accessibility:

  * If user has `prefers-reduced-motion: reduce`, disable marquee and show static wrapped layout.

Implementation suggestion:

* Duplicate logo list (two tracks) for seamless looping.
* Use CSS keyframes translateX from `0` to `-50%` (depending on track width).

### 4) Desktop/Tablet Hover Effects (No Scrolling)

* Each logo should be in its own “card” or “pill” container:

  * subtle border
  * soft shadow
  * slight background tint depending on theme
* On hover:

  * scale up slightly (e.g. `transform: scale(1.06)`)
  * increase shadow depth
* Keep spacing consistent and aligned.
* Logos should not look “stuck together”—each one feels separate like the reference.
