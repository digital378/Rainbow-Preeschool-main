# docs/archive — Historical Snapshots

The files in this directory are historical inventories created during manual URL audits
and are superseded by the live source of truth: **`shared/sitemap-entries.ts`**.

| File | Description |
|---|---|
| `RPI_Pages_Inventory.xlsx` | Manual page inventory (June 2026). Superseded by `shared/sitemap-entries.ts`. |
| `rainbowpreschools-url-audit.xlsx` | URL-level audit export (June 2026). Superseded by `shared/sitemap-entries.ts`. |

Do not update these files. For current URL lists, priorities, and changefreqs, edit
`shared/sitemap-entries.ts` — it is the single source of truth for the XML sitemap
and all predeploy URL checks.
